# Sorting Algorithms: Visual Reverse Engineering and Implementation
## Overview
A collection of sorting algorithms independently implemented through the examination and reconstruction of visual algorithm demonstrations. The project explores the logic of different sorting strategies and how this affects computational (time) complexity.
## Motivation
The project was driven by an interest to understand the mechanisms behind sorting algorithms and why they behaved the way they did/had the time complexities they did. I was especially inspired by Codility's lessons, which covered time complexity and sorting.

## Implemented Algorithms  
| Algorithm |	Average Time Complexity |	Worst-case Time Complexity |
| --- | --- | --- |
| Bubble Sort |	O(n²) |	O(n²) |
| Selection Sort |	O(n²) |	O(n²) |
| Insertion Sort |	O(n²) |	O(n²) |
| Merge Sort |	O(n log n) |	O(n log n) |
| Quick Sort |	O(n log n) |	O(n²) |
| Heap Sort |	O(n log n) |	O(n log n) |
| Shell Sort |	O(n log n) |	O(n²) |
